# Victor Public Higher Secondary School — Website

A responsive, animated one-page school website built with plain HTML, CSS and JavaScript.

## Included
- School logo/emblem from the supplied image
- School building photo
- Sir Tony leadership/vision section
- Principal and Disciplinary Head sections
- About, Vision, Leadership, Academics, Gallery and Contact sections
- Responsive mobile navigation
- Scroll reveal animations
- Floating cards and hover animations
- Scroll progress indicator
- Back-to-top button
- Contact form UI

## Important
The displayed email `info@victorpublicschool.edu.pk`, office hours and some vision copy are provisional website content because official contact details were not supplied in the request. Replace them with the school's confirmed information before publishing.

## Run
Open `index.html` in a browser, or deploy the folder to any static host.
